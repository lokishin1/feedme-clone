# URL → Markdown → LLM

웹 페이지 URL을 붙여넣으면 본문을 Markdown으로 변환해 보여주고, 복사·다운로드하거나 ChatGPT·Claude에 바로 넘길 수 있는 단일 화면 서비스입니다.

승인된 화면: [prototype.html](prototype.html). 화면 구성, 상태(빈 상태·변환 중·결과·저자 없음·오류 3종), 안내 문구, 좁은 화면의 쌓임 순서는 이 프로토타입을 기준으로 구현합니다. 프로토타입은 참고용이며 제품 코드가 아닙니다. 이 문서의 동작 규칙과 다르면 이 문서를 따르고 차이를 알려 주세요.

## 사용자에게 보이는 결과

한 화면에서 입력 → 변환 → 결과 확인 → 내보내기가 이어집니다. 계정, 기록, 저장은 없습니다.

### 1. 입력
- URL 입력창, 변환 버튼, 지우기 버튼이 있다. Enter로도 변환한다.
- 지우기 버튼은 URL, 결과, 오류 표시를 모두 비워 처음 상태로 되돌린다. 선택한 프롬프트는 그대로 둔다.

### 2. 변환
- 서버에서 해당 페이지를 가져와 **defuddle 라이브러리**로 본문을 Markdown으로 추출한다(필수 요구). defuddle.md 호스팅 API가 아니라 라이브러리를 쓴다.
- 변환 중에는 진행 중임이 보이고, 변환 버튼은 비활성화된다.

### 3. 결과 확인
- 결과 상단 헤더에 페이지 제목과 저자를 보여준다. 저자 정보가 없으면 저자 줄은 표시하지 않는다.
- 헤더 아래에 Markdown을 렌더링한 본문을 보여준다.

### 4. 내보내기
| 동작 | 내용 |
|---|---|
| 복사하기 | 순수 Markdown을 클립보드에 복사. 프롬프트는 붙지 않는다. |
| .md 다운로드 | 순수 Markdown 파일을 내려받는다. 프롬프트는 붙지 않는다. |
| ChatGPT로 열기 | [선택한 프롬프트 + 빈 줄 + Markdown]을 클립보드에 복사하고 ChatGPT 새 채팅을 새 탭으로 연다. 사용자는 붙여넣기만 하면 된다. |
| Claude로 열기 | 위와 같되 Claude 새 채팅을 새 탭으로 연다. |

- 프롬프트가 선택되지 않았으면 "열기"는 Markdown만 복사한다.
- "열기"를 누르면 "클립보드에 복사했어요. 붙여넣으세요" 같은 안내가 보여, 새 탭에서 무엇을 해야 하는지 알 수 있다. "복사하기"도 복사됐음을 보여준다.

### 5. 프롬프트
- 프리셋: **요약해줘 / 한국어로 번역해줘 / 쉽게 설명해줘**, 그리고 **직접 입력**.
- 기본값은 선택 없음이다. 프리셋은 한 번에 하나만 고르고, 선택된 항목을 다시 누르면 해제된다.
- "직접 입력"을 고르면 텍스트 입력창이 나타난다. 내용이 비어 있으면 프롬프트 없음과 같다.
- 직접 입력한 내용은 1회용이다. 어디에도 저장하지 않으며 새로고침하면 사라진다.
- 프롬프트는 "ChatGPT·Claude로 열기"에만 적용된다.

### 6. 다크모드
- 화면에서 라이트/다크를 바꾸는 토글이 있다.
- 처음 방문 때는 시스템 설정을 따르고, 토글로 바꾼 값은 브라우저에 기억한다.

### 상태
- **빈 상태**: 처음 화면은 URL 입력과 사용 방법이 한눈에 보인다.
- **로딩**: 변환 중 표시.
- **오류**: 잘못된 URL, 접속 실패, 본문을 찾지 못함을 입력창 아래에 보여준다. 입력한 URL은 유지한다.
- **성공**: 헤더 + 렌더링된 Markdown + 내보내기 동작.

## 수용 기준

1. 유효한 기사 URL을 입력하고 변환하면 제목, 저자(있을 때), 렌더링된 Markdown 본문이 보인다.
2. 지우기를 누르면 입력창, 결과, 오류가 모두 사라지고, 선택한 프롬프트는 유지된다.
3. 복사하기 후 클립보드 내용은 프롬프트 없는 Markdown과 같다. 프롬프트를 선택한 상태에서도 마찬가지다.
4. `.md` 다운로드 파일의 내용은 화면의 Markdown과 같다.
5. 프리셋을 고르고 "ChatGPT로 열기"를 누르면 클립보드는 "프롬프트, 빈 줄, Markdown" 순서이고, ChatGPT 새 채팅이 새 탭으로 열린다. "Claude로 열기"도 같다.
6. 프롬프트 없이 "열기"를 누르면 클립보드는 Markdown만 담고 새 탭이 열린다.
7. "직접 입력"을 고르면 입력창이 나타나고, 입력한 문구가 "열기"의 앞부분으로 쓰인다. 새로고침 후에는 남아 있지 않다.
8. 프리셋을 다시 누르면 선택이 해제되고, 이후 "열기"는 프롬프트 없이 동작한다.
9. 잘못된 URL이나 접속 불가 주소를 넣으면 오류가 보이고 입력값은 유지된다.
10. 다크모드 토글이 라이트/다크를 바꾸고, 새로고침 후에도 바꾼 값이 유지된다.
11. 좁은 화면에서도 입력, 결과, 내보내기 동작이 숨겨지지 않고 순서대로 쌓인다.

## 확정된 제약과 이유

- **defuddle 라이브러리를 변환에 사용한다.** 사용자의 필수 요구이며, 서버에서 HTML을 가져와 변환한다. 브라우저에서 직접 가져오면 대부분 사이트가 CORS로 막힌다.
  - 확인한 내용: `defuddle@0.19.6` + `linkedom@0.18.14`를 임시 폴더에서 실행해 Wikipedia(Markdown 문서, 약 3.3만 자)와 Next.js 블로그(약 1.6만 자)에서 제목·저자·Markdown 본문이 나오는 것을 확인했다. 두 번째 페이지는 저자가 비어 있었다.
- **"열기"는 클립보드 복사 + 새 탭 방식이다.** 본문이 수만 자라 URL 파라미터로 넘기면 길이 한도에 걸릴 가능성이 높고, 잘려도 사용자가 알기 어렵다. 클립보드 방식은 글 길이와 무관하게 동작한다.
- **프롬프트는 "열기"에만 붙는다.** 복사와 다운로드는 변환 결과 자체를 가져가는 동작이라, 프롬프트를 섞으면 순수 Markdown을 얻을 방법이 사라진다.
- **저장하지 않는다.** URL, 결과, 직접 입력 프롬프트는 어디에도 저장하지 않는다. 다크모드 선택만 예외다.
- **UI 구성은 [ui-composition](../../decisions/ui-composition.md) 결정을 따른다.** 버튼, 입력, 오류·로딩 상태 같은 일반 UI는 shadcn 공식 component와 semantic token으로 구성하며, 공통 shell 안에서 입력 → 결과 → 내보내기 순서의 위계를 만든다.

## 가정 (바꾸고 싶으면 말해 주세요)

- 지우기는 프롬프트 선택을 초기화하지 않는다.
- `.md` 파일 이름은 페이지 제목에서 만들고, 제목이 없으면 기본 이름을 쓴다.
- 처음 화면의 사용 방법 안내는 짧은 문구 수준이다.
- 본문에 쓰이는 이미지와 링크는 원본 URL 그대로 보여준다.

## 범위 밖

- 로그인, 변환 기록, 즐겨찾기, 공유 링크, URL 쿼리로 자동 변환하는 딥링크.
- ChatGPT·Claude에 본문을 URL 파라미터로 직접 전달하는 방식과 API 연동.
- 스펙이 요구하지 않은 보안 하드닝, 속도 제한, 캐시(이 프로젝트의 검증 예산 기준).

## 보류

- 없음.

## 남은 위험

- 서버가 임의 URL을 가져오므로, 내부망 주소 접근 같은 악용 가능성이 있다. 범위 밖으로 둔 하드닝이며, 공개 배포 전에 다시 판단해야 한다.
- 자바스크립트로 본문을 그리는 페이지, 로그인·유료 벽이 있는 페이지는 본문이 비거나 일부만 나올 수 있다. 이 경우 "본문을 찾지 못함" 오류로 처리된다.
- 새 탭이 열린 뒤 붙여넣기는 사용자가 직접 해야 한다. 안내 문구가 이 점을 충분히 알리는지는 실제 화면에서 확인이 필요하다.
- 매우 긴 글은 ChatGPT·Claude의 입력 한도를 넘을 수 있다. 이 서비스는 길이를 줄이지 않는다.
