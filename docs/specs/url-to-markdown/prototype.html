웹 페이지를 Markdown으로

URL을 붙여넣으면 본문만 뽑아 드려요. 복사하거나 ChatGPT·Claude에 바로 넘겨 보세요.

올바른 URL이 아니에요
http:// 또는 https://로 시작하는 전체 주소를 입력해 주세요.
페이지에 접속하지 못했어요
주소가 맞는지, 로그인 없이 외부에서 열 수 있는 페이지인지 확인해 주세요.
본문을 찾지 못했어요
로그인이 필요하거나 자바스크립트로 화면을 그리는 페이지는 본문이 비어 보일 수 있어요.

이렇게 사용해요

  1. 1URL을 붙여넣고 변환을 누르세요. 광고와 메뉴를 뺀 본문만 가져와요.
  2. 2제목, 저자, 본문이 Markdown으로 정리돼 보여요.
  3. 3복사·다운로드하거나, 프롬프트를 골라 ChatGPT·Claude로 열기를 누르세요.
